# In Good Company exhibition page

Upload `in-good-company-standalone.html` to your website hosting and rename it `index.html`. The artwork and styles are embedded, so this file works on its own. No installation or build is needed.

Alternatively, upload `index.html` and `in-good-company-poster.png` together. This version keeps the image separate and is smaller.

The PNG poster is also ready to use independently. Its imagery is original AI-generated promotional artwork, not documentation of works in the exhibition. Created with built-in image generation.

The visitor schedule uses the latest confirmed dates in this task: October 9 to November 21, 2026. The older invitation and curatorial Word documents still contain earlier dates, so they were not used for the visitor schedule.

The domain has not been connected and the page has not been published. These files can be used with your existing hosting provider.
